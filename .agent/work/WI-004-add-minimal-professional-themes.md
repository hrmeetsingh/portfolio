# WI-004: Add minimal professional themes

## Goal

Add three minimal, professional daisyUI themes (ledger light, graphite dark, paper warm light) with 0.25rem radius and Inter / IBM Plex Sans fonts, alongside the existing themes.

## Acceptance criteria

- [x] ledger, graphite and paper exist alongside the existing themes and appear in the switcher
- [x] Corner radius is 0.25rem on boxes, buttons, badges and tabs
- [x] New fonts apply only to the new themes (Inter: ledger, graphite; IBM Plex Sans: paper)
- [x] `npm run build` passes; WCAG AA contrast on all content pairs (reviewer-computed, lowest 4.80)
- [ ] User checks all three themes visually in `npm run dev`

## Plan

1. Define themes in `src/constants/professional-themes.ts`; register in `tailwind.config.js`.
2. List names in `gitprofile.config.ts`; set `defaultTheme: 'ledger'`.
3. Load fonts in `index.html`; add per-theme `body` font rules in `index.css`.
