## Purpose
Holds `gitprofile.tsx`, the top-level `GitProfile` component that orchestrates the whole page. It sanitizes the config, fetches the GitHub profile and projects, picks the theme, and renders each card (avatar, details, skills, experience, education, certifications, publications, projects, blog, books, footer) or an error page. Each card lives in its own subfolder with its own note.

## Key concepts
- `GitProfile` takes `config`, runs `getSanitizedConfig` from [[src-utils]] once, and keeps `profile`, `githubProjects`, `error`, `loading` and `theme` in state.
- `getGithubProjects` queries the GitHub search API in `automatic` (by user, sorted, limited) or `manual` (listed repos) mode.
- `loadData` fetches the user from `api.github.com`; errors map to `INVALID_CONFIG_ERROR`, `setTooManyRequestError`, `INVALID_GITHUB_USERNAME_ERROR` or `GENERIC_ERROR` from [[src-constants]].
- Types come from [[src-interfaces]]; global styles come from [[src-assets]].

## Gotchas
- Unauthenticated GitHub API calls are rate limited (429 shows the too-many-requests page with reset time).
- An empty sanitized config (sanitizer threw) triggers the invalid config error rather than rendering.
