## Purpose
TypeScript interfaces shared across components. `sanitized-config.tsx` mirrors the global `Config` type from [[root]] but with every optional field made concrete, and the small `Article`, `GithubProject` and `Profile` types describe fetched data. Components import these instead of the raw config types.

## Key concepts
- `SanitizedConfig` is the full normalized config produced by `getSanitizedConfig` in [[src-utils]].
- Per-section types: `SanitizedGitHubProjects`, `SanitizedExternalProjects`, `SanitizedSEO`, `SanitizedSocial`, `SanitizedResume`, `SanitizedBlog`, `SanitizedBooks`, `SanitizedThemeConfig`, etc.
- `Profile` (avatar, name, optional bio/location/company) is the GitHub user shape used by [[src-components]].
- `GithubProject` and `Article` describe project and blog items rendered by cards.

## Gotchas
- Sanitized types must be updated together with `global.d.ts` and `getSanitizedConfig` when adding a config option.
