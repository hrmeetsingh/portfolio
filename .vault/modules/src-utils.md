## Purpose
Single-file helper module (`index.tsx`) used by nearly every component. It normalizes the user config, resolves the initial theme, and offers small UI and analytics helpers.

## Key concepts
- `getSanitizedConfig(config)` fills defaults for every option and returns `{}` on any exception, which the app treats as an invalid config.
- `getInitialTheme` order: fixed default if switch disabled, then valid saved theme in localStorage, then prefers-color-scheme (dark), then default theme.
- `isDarkishTheme` checks a hardcoded list of dark daisyUI themes.
- `skeleton` renders a pulse placeholder div; `getLanguageColor` reads [[src-data]].
- `setupHotjar` and `ga.event` wrap analytics; types and constants come from [[src-interfaces]] and [[src-constants]].

## Gotchas
- `getSanitizedConfig` swallows errors silently, so a typo that throws shows only the generic invalid config page.
- `isDarkishTheme` is a fixed list; new dark themes must be added manually.
- `ga.event` relies on a global `gtag` and only logs errors if it is missing.
